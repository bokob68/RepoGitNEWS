# Codex Automation Prompt

Използвай само файловете в това repo.

Задача:

1. Прочети `news.txt`, `PROMPT_RULES.md` и `news1.txt`.
2. Създай или обнови `review_latest.txt`.
3. Форматът на изхода трябва да следва практическия стил на `news1.txt`.
4. Използвай само новините от `news.txt`.
5. Не пропускай валиден URL.
6. Не добавяй външни източници или нови URL-и.
7. Разрешени секции:
   - Политика
   - Икономика
   - Свят
   - Технологии
8. Не добавяй увод, заключение, бележки или citations.
9. След като обновиш `review_latest.txt`, запази файла в repo-то.

Изход:

- Единствен краен файл: `review_latest.txt`

Важно:

- `news1.txt` е референтният пример за реалния формат.
- Работи по моя GitHub repo workflow през Codex app акаунта ми.
